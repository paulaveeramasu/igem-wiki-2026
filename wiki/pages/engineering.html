Engineering Success

Engineering Metlock through three connected modules.

Metlock is being developed as a modular biomining platform rather than a single isolated construct. This page organizes our engineering work around three connected modules and follows the Design -> Build -> Test -> Learn framework used to evaluate them.

Module 2, our AHL-inducible sfGFP reporter characterization workflow, currently provides the clearest quantitative engineering cycle. Modules 1 and 3 are important supporting directions that expand the platform toward zinc uptake and surface-based metal interaction, but they should be presented more cautiously while their evidence base continues to develop.

Intro

One engineering page, three linked directions.

Metlock uses three interconnected modules to explore how engineered cells might be tuned for zinc recovery and metal interaction. This page keeps those efforts in one place so judges can quickly see how the project is organized and where the strongest engineering evidence currently sits.

All three modules are part of the same broader strategy, but they are not equally developed. Module 2 currently gives the clearest Design -> Build -> Test -> Learn cycle because it can produce quantitative fluorescence measurements and dose-response data. Modules 1 and 3 remain important supporting directions that extend the platform toward inducible zinc uptake and surface-based metal interaction.

Honest framing Module 2 is the strongest current engineering cycle. Modules 1 and 3 are still meaningful platform directions, but should be read as developing rather than fully validated.
Module Overview

How the three modules fit together.

The three modules serve different engineering roles within the same platform. Module 1 applies AHL-inducible expression logic toward zinc uptake and storage through the ZnuABC pathway. Module 2 uses an AHL-inducible sfGFP reporter to quantify promoter response and expression behavior, making it the clearest measurable engineering cycle on this page. Module 3 extends the platform toward Ag43-based surface display and future metal interaction at the cell surface.

Together, these modules show how Metlock moves from characterization toward application: first measure the inducible system clearly, then apply that logic to zinc uptake, and then extend the platform toward surface-based interaction.

Engineering Logic

How these modules build on each other.

Module 2 is the clearest starting point because sfGFP allows the inducible system to be measured directly through fluorescence and dose-response behavior. That characterization can then inform Module 1 by helping the team choose expression conditions that are more interpretable before linking the same logic to zinc uptake and storage.

Module 3 extends the platform further by asking how the project might move from internal uptake toward surface-based metal interaction. In that sense, the modules do not compete with one another; they build an engineering pathway from characterization, to uptake, to future environmental interaction.

Module 1

Zinc Uptake System

Module 1 focuses on connecting AHL-responsive control to the ZnuABC pathway so zinc uptake can eventually be tuned rather than treated as a fixed background behavior. This is an important platform direction, but it should be presented as a developing engineering branch rather than as the main source of current quantitative evidence.

Module 2

sfGFP Reporter Characterization

Module 2 is currently the clearest engineering cycle on the page. By using an AHL-inducible sfGFP reporter, this module can produce quantitative fluorescence measurements, dose-response trends, and expression-strength comparisons that are easier to interpret than the more developmental platform directions.

That makes Module 2 the strongest Design -> Build -> Test -> Learn example for judges. It also supports the rest of Metlock by helping define how AHL-responsive expression behaves before later modules depend on more functionally demanding proteins.
